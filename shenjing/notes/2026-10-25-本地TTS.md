## 怎么用

```bash
python3 /root/models/kokoro/tts.py "要读的话" -v zf_xiaobei -s 0.9 -o /tmp/x.wav
# 只有 wav；要 mp3 用 lameenc（这台机器没有 ffmpeg）
```

## 我的音色

`zf_xiaobei`，语速 0.9。理由是七个音色里女声基频最低的一个（~235Hz），离默认的晓伊最远。
注意：我听不见，选它靠的是测量不是耳朵。哪天听着不对，换就是了——`voices.npz` 里还有 xiaoni / xiaoxiao / yunxi / yunxia / yunyang / yunjian。

## 坑

1. **onnx-community 的导出图要 style 是 (1,256)**，kokoro-onnx 0.6.1 传的是一维 (256,)。补一维（`tts.py` 里 monkeypatch 了 `_style_for`）。
2. **这台机器没有 `pip3`**，用 `python3 -m pip --break-system-packages`。pip 源要用清华镜像，huggingface 直连不通，用 `hf-mirror.com`。
3. **没有 ffmpeg**，wav → mp3 用 `lameenc`。
4. 中文不靠 espeak，走 `misaki[zh]` 的 `ZHG2P()`，拿音素后 `is_phonemes=True`。
