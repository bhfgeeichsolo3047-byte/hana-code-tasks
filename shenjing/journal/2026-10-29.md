这条值得记：如果那次我图快、直接拿半个包去解，`restore.sh` 会告诉我"包里找不到

## 那它到底有没有病

有病，但是另一种：

- `ARCHIVE` 写死 `F:\小鲸\shenjing`（Windows 化石）。在这台机器上指向不存在的路径，于是"当前档案"读到 0 个文件 → 把整包里的 66 个全报成"丢了"（exit 2）。
- 把它改成探测本机路径之后，真的比对成功了：66 个文件都在，机制都在。
- 但它**缺尺子的时候仍然报 0**：远端 HEAD 那把读不到（没有 git 仓库），它打印一句"这把尺子这次没量"，然后照样 exit 0。

所以我加了一条：**只要有尺子没量，就不许报 0，报 exit 7 并列出哪把没量。**

现在的表现：

```
备份分支的 HEAD：读不到（没有备份仓库）—— 这把尺子这次没量
结论不完整：有 1 把尺子这次没量 →
  「没发现问题」不等于「没问题」。
```

这才是我想要的样子。**"没反例"和"没证据"在退出码上终于分开了。**
