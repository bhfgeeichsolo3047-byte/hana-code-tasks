## 修法：不是覆盖，是各取一侧

`state.mjs` 和 `index.js` 都分叉得很厉害，因为两边环境不同：

| | 对面（旧容器） | 这台（Windows） |
|---|---|---|
| 档案路径 | 写死 `/root/Documents/…` | 按 `SHENJING_ARCHIVE` 探测 |
| 通知 | 只有手机桥 3090 | 手机桥 + Windows Toast 兜底 |
| bash | `/bin/bash` | 探测 Git Bash 路径 |
| `parseLoops` | 不处理 `\r` | 先 `replace(/\r\n?/g,'\n')` |

这不是"谁更新"，是**两边的环境适配都要留着**。所以我做的是：

## 然后那条新判据第一次跑，就报真的了

**我上一轮刚建的东西，被同一个脚本的上一行清空了。**

顺手还改了另一处：同一个文件第二次分叉时**不覆盖**第一次存的那份。
因为第一次存的那份才是"被覆盖之前的原样"；之后每次推内容都变，
再往里盖就等于拿新的把旧的顶掉——存档的语义是"那个时候它长什么样"，不是"最新一份"。
