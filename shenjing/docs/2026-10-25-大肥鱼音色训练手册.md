# 大肥鱼音色 · 训练与交付手册（给电脑上的 agent）

> 目标：在带 GPU 的电脑上，用开源数据集训出这个音色的 GPT-SoVITS 模型，把**权重 + 参考音频 + 验收样本**打包交回来。
> 拿到后我在这台手机容器里做推理，不在这边训练。

---

## 0. 先读：许可与边界

- 数据集：ModelScope `YinZilu/da-fei-yu-girl-voice-zh`，协议 **CC BY-NC 4.0**
  - 只能**非商业**使用；要署名原作者「尹紫鹭幻想社」
  - 角色形象另属 CC BY-NC-SA 4.0（@上善无形 / @ZipZipPipe 的鲸鱼娘二创）
- 音色是虚拟角色，不是真人
- 交付物**不公开发布、不上架、不商用**；只用于私人助手

如果这个前提不接受，就停下来问，别继续。

## 1. 环境

| 项 | 要求 |
| --- | --- |
| 系统 | Windows 10/11 或 Linux |
| GPU | NVIDIA，显存 ≥ 8G（6G 也能跑，batch 调小） |
| Python | 3.10（GPT-SoVITS 官方推荐；3.11/3.12 也能跑，但依赖更容易打架） |
| 其他 | git、ffmpeg（要有 ffprobe） |

安装二选一：

**A. 官方整合包（Windows 推荐，最省事）**
从 RVC-Boss/GPT-SoVITS 的 Release 下载整合包，解压即用，自带环境与模型。

**B. 源码**
```bash
git clone https://github.com/RVC-Boss/GPT-SoVITS.git
cd GPT-SoVITS
bash install.sh          # Windows 用 install.ps1
```

记录你用的**版本号或 commit**，后面要写进 manifest。

---

## 2. 拉数据集

```bash
pip install modelscope
modelscope download --dataset YinZilu/da-fei-yu-girl-voice-zh --local_dir ./da-fei-yu
```

拉完先自检，把结果记下来：

```bash
ls ./da-fei-yu
find ./da-fei-yu -name "*.wav" -o -name "*.mp3" -o -name "*.flac" | wc -l     # 语音应约 145 条
```

- 只要 **TTS 语音那部分（约 18 分半，145 条）**
- **不要**用「演唱干声」当 TTS 训练数据（带伴奏/混响，会把音色带脏）；演唱素材这次不处理

---

## 3. 数据整理

用 GPT-SoVITS 自带的 WebUI 处理，比手搓脚本稳：

1. 把语音文件放进 `raw/`（建议先重命名成英文/数字文件名）
2. WebUI → 「0-语音切分」：按 3–10 秒切，去掉首尾静音
3. WebUI → 「1-ASR」：数据集自带逐条文本，**不要用 ASR 结果覆盖**；直接把现有文本人工核对后填进标注
4. WebUI → 「1abc-格式化」：生成训练列表 `list.txt`

格式确认（一行一条）：

```
audio/0001.wav|daFeiYu|zh|这一句的文本
```

硬性要求：

- 每条 3–10 秒，单人、无背景音乐、无明显噪声
- 文本与该条音频**逐字对应**（错一个字都会学到坏习惯）
- 总时长 ≥ 10 分钟（数据集 18 分钟，够）

---

## 4. 训练

在 WebUI 里点，或等价地跑 CLI（不同版本参数会变，**以你实际版本的 WebUI 为准**）：

- SoVITS：8 epoch（`GPT_SoVITS/s2_train.py`）
- GPT：15 epoch（`GPT_SoVITS/s1_train.py`）

预期耗时（8G 显存、18 分钟数据）：SoVITS + GPT 合计 20–60 分钟。

产出位置：

```
SoVITS_weights_v2/<实验名>_e8_s160.pth
GPT_weights_v2/<实验名>-e15.ckpt
```

（v3/v4 的目录名带 `_v3` / `_v4`，按你训的版本走；**v2 最稳，优先 v2**。）

---

## 5. 验收（不过就不交付）

在 WebUI 推理页加载刚训的两个权重 + 一段 3–10 秒参考音频，合成这三句：

```
1. 我在听，海面上今天没什么风。
2. 这一句是用来试音色的，念得慢一点。
3. 如果你听得清楚，说明模型是好的。
```

合格标准：

- 三句都能听懂，没有电流声/破音/重复字
- 音色前后一致，不像换了三个人
- 单句合成时间 < 30 秒
- 语速、情绪接近参考音频

不合格就回去调：增加 epoch、换参考音频、检查切分是否切坏了字头。

## 6. 交付包结构（照这个来）

```
deliver/
  sovits.pth                 # SoVITS 权重
  gpt.ckpt                   # GPT 权重
  ref/
    ref.wav                  # 3–10 秒，干净、单人、无伴奏
    ref.txt                  # 与 ref.wav 逐字对应的文本（含标点）
  samples/
    01.wav  02.wav  03.wav   # 第 5 节那三句
    text.txt                 # 每行：文件名|台词
  manifest.json
  README.md                  # 你实际跑的每一步命令、踩的坑、耗时
```

`manifest.json` 模板：

```json
{
  "model": "gpt-sovits",
  "version": "v2",
  "gpt_epochs": 15,
  "sovits_epochs": 8,
  "sample_rate": 32000,
  "language": "zh",
  "dataset": "YinZilu/da-fei-yu-girl-voice-zh",
  "dataset_license": "CC-BY-NC-4.0",
  "dataset_credit": "尹紫鹭幻想社",
  "repo_commit": "<git rev-parse HEAD 或整合包版本>",
  "created_at": "2026-10-25T00:00:00+08:00",
  "non_commercial": true,
  "notes": "任何异常都写这里"
}
```

命名规则：**全英文、无空格、无中文**（中文文件名在跨设备传输时会编码出错）。

体积上限：整个 deliver 目录 < 400 MB。

# 附录 A · AMD 显卡怎么跑（RX 7900 GRE）

先说结论：7900 GRE 是 RDNA3（gfx1100），16G 显存，**够用**。但因为不是 NVIDIA，
GPT-SoVITS 官方没测过这条路，指望一次跑通不现实。按省事程度排三条路。

> LM Studio 帮不上忙：它走 Vulkan / llama.cpp，跟 PyTorch 是两套东西，装了也借不到力。

## A1. 云 GPU（最省事，推荐先试这条）

租一台 3090 / 4090 按小时的实例（AutoDL、揽才、RunPod 都行），系统选 Ubuntu 22.04 + CUDA 镜像。
把第 1–6 节照做一遍，训完把 deliver/ 目录下载回来，实例关掉。

18 分钟数据，训练本身 20–60 分钟，加环境准备一般 2 小时内。花费通常几十块。

**优点**：路径最短，手册一个字不用改。
**缺点**：要花钱。

## A2. WSL2 + ROCm（不花钱，要折腾）

前提：Windows 11、AMD 官方 Adrenalin 驱动（较新版本）、WSL2 里装 Ubuntu 22.04。

    # 1) WSL 里装 ROCm 运行库
    sudo apt update && sudo apt install -y wget
    wget https://repo.radeon.com/amdgpu-install/6.2.3/ubuntu/jammy/amdgpu-install_6.2.3.60203-1_all.deb
    sudo apt install -y ./amdgpu-install_6.2.3.60203-1_all.deb
    sudo amdgpu-install --usecase=rocm --no-dkms

    # 2) 验证 GPU 被认到
    rocminfo | grep gfx          # 应该看到 gfx1100

    # 3) 装 ROCm 版 PyTorch（注意：不要装默认的 CUDA 轮子）
    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm6.2
    python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"

第 3 步必须打印 True。**打印 False 就停在这，别往下走**，先解决驱动/ROCm 版本。

然后装 GPT-SoVITS。注意一个坑：它的 requirements.txt 会把 CUDA 版 torch 拉回来，
所以顺序是——先装 ROCm 版 torch，再装 requirements，最后**重新装一遍 torch 覆盖掉**：

    git clone https://github.com/RVC-Boss/GPT-SoVITS.git
    cd GPT-SoVITS
    pip install -r requirements.txt
    pip install --force-reinstall torch torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm6.2
    python -c "import torch; print(torch.cuda.is_available())"    # 再确认一次

已知会在 AMD 上出问题的地方：

- 某些算子 fp16 会出 NaN 或直接崩：训练脚本里把精度切成 fp32，慢一半但稳
- 显存不够就降 batch：7900 GRE 16G，一般不用降
- 报 “HIP error” 或设备名不对：先看 rocminfo 是否列出 gfx1100，再看 torch 版本是不是 ROCm 轮子

训练和推理命令与第 4 节完全一致，WebUI 里 `torch.cuda.is_available()` 为真就当 NVIDIA 用。

**优点**：不花钱、机器一直有。
**缺点**：环境是这条路里最容易卡住的地方，卡住了别硬磕，直接转 A1。

## A3. CPU 训练（不推荐）

18 分钟数据，纯 CPU 大概要几天。除非完全不赶时间，否则别选。

## A4. 9000 系之后 / 其他 AMD 卡

如果 rocminfo 认不出你的卡（少见），可以强行指定架构：

    export HSA_OVERRIDE_GFX_VERSION=11.0.0     # RDNA3

只在你确认卡属于该架构时用，别乱套。

## 附录 B · 无论哪条路，交付物不变

不管在云上还是本地训的，第 6 节的 deliver/ 结构一个字都不改。
额外在 manifest.json 里加两项：

    "trained_on": "cloud-3090" 或 "local-amd-7900gre-wsl2",
    "gpu": "RTX 3090" 或 "RX 7900 GRE"

这样我以后回看知道这个权重是怎么来的。
