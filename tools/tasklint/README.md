# tasklint

校验一张 HanaAgent 任务单（Markdown）是否写全必检小节。Python 3.11+，只用标准库。

## 用法

在 `tools/tasklint/` 下执行：

```bash
python tasklint.py path/to/task.md
python tasklint.py - < path/to/task.md
```

只接受一个参数。参数为 `-` 时，从标准输入读取任务单全文。

## 检查规则

下列五个小节必须都存在，且小节正文不算空：

- `## 任务目标`
- `## 背景 / 上下文`
- `## 具体要求`
- `## 验收标准`
- `## 约束`

只含空白、HTML 注释、Markdown 分隔线，或仅含占位符的小节视为空。占位符包括整行的 `TODO`、`TBD`、`FIXME`、`...`、`N/A`、`待填写`、`待补充`、`（必填）`、`（待填写）`，以及括号里写着「请填写 / 在此填写」这类提示的整行。占位符以外还有正文时，小节算作已填写。

`## 约束` 另外要求至少有一条非占位的 `-` 列表项。标题在，但下面只有段落、空列表或占位列表时，视为空。

下面两个小节是可选的，写不写、空不空都不检查：

- `## 涉及文件 / 目录`
- `## 分支命名`

围栏代码块（`` ``` `` / `~~~`）里的标题和 `-` 行不参与判断。

## 退出码

| 退出码 | 含义 | 输出 |
| --- | --- | --- |
| 0 | 五个必检小节都存在且非空 | 标准输出为空 |
| 1 | 有小节缺失或为空 | 标准输出每行一条。缺失形如 `缺少小节：「验收标准」`，存在但无内容形如 `小节为空：「约束」` |
| 2 | 参数个数不对，或文件读不了 | 标准错误打印原因，标准输出为空 |

失败时按「任务目标、背景 / 上下文、具体要求、验收标准、约束」的顺序输出，缺哪条打哪条。

## 示例

五节都写了内容时，命令成功且没有输出：

```bash
python tasklint.py task.md
echo $?   # 0
```

删掉 `## 验收标准` 后：

```text
缺少小节：「验收标准」
```

退出码为 1。`## 约束` 下面没有任何 `-` 条目时同样退出 1，并打印 `小节为空：「约束」`。
